# CyberOrg English Patch

An English translation patch for the Japanese PSX release of **CyberOrg**.
You need your own Japanese game bin/cue set as no game files or copyrighted work is distributed here,

This was translated with the assistance of OpenAI Codex. The text was reviewed and edited by a human where necessary.

This has not been fully tested and had a full playthrough to ensure all text has been found and translated, or there are no issues.
The first few levels have been tested to work properly in Duckstation and the MiSTerFPGA PSX Core.

All found text and UI has been translated.

The FMV subtitles were translated from their original japanese subtitles, they were not matched up to the exact english dialog that already existed in the game.
This was done like thie because:
  1. Space and rendering of the english translations caused too many issues to fit them properly.
  2. They're substantively the same, but convey the english dialog in a different light, so I thought it was of interest to keep them like this.
  3. Animes tend to have different subtitles than the actual english dubs, so it almost feels natural to do the same here.


Note: Duckstation has a rendering issue with some UIs in this game that do not occur on real hardware or the MiSTerFPGA core. Do not report issues with missing/broken UI graphics here, they are not caused by this patch.

## Patching manually

Apply the xdelta patch to its matching original bin file.
